# Prismatic Shards Theme Architecture

## Overview

Prismatic Shards is built on the actual Omarchy theme architecture, following Omarchy's conventions for theming. This document explains the architectural decisions and integration points.

## Omarchy Theme Architecture

Omarchy themes follow a specific directory structure and file format:

### Core Files

- **`colors.toml`** — The Omarchy theme contract. This file is read by `omarchy-theme-set` and generates configurations for terminal, btop, Chromium, Hyprland, Neovim, Helix, VS Code, and Obsidian from a single source of truth.

- **`shell.toml`** — UI theming for the Omarchy shell. This is a hand-written replacement for the shell.toml that would be generated by `omarchy-theme-set-templates`. Omarchy never overwrites a file a theme ships itself, so these are the tokens the running Omarchy shell reads into its `Color` and `Style` QML singletons.

- **`hyprland.lua`** — Hyprland compositor integration. Omarchy loads this file as `omarchy.current.theme.hyprland`, which is where a theme is allowed to shape the compositor. Themes installed with `omarchy theme install` do not keep this file — Omarchy drops `.lua` from themes cloned out of a git repo because a compositor config can run code.

### Theme Structure

```
theme/
├── colors.toml                    # Main color palette
├── shell.toml                     # UI surfaces and controls
├── hyprland.lua                   # Compsitor effects
├── variants/
│   ├── light/                     # Light theme variants
│   │   ├── colors.toml
│   │   ├── shell.toml
│   │   └── hyprland.lua
└── assets/                        # Theme assets (icons, wallpapers, etc.)
```
